# Clean Learning-Path UI Principles Used in v1.8

The goal is not to copy JoinAI. The useful lesson is information hierarchy.

Bunny English now follows these principles:

1. One page answers one question.
   - Learn overview: "Which level am I on?"
   - A0 journey: "What lesson comes next?"
   - Lesson: "What do I need to understand/do now?"

2. Use a visible hierarchy.
   - Level → Chapter → Lesson.

3. Give one obvious next action.
   - Continue A0.
   - Up next lesson.

4. Keep metadata compact.
   - minutes
   - short steps
   - completion state

5. Future content is visible but quiet.
   - A1–C2 rows are locked/planned rather than giant promotional cards.

6. Do not turn the path into a game board.
   - no unnecessary zig-zag nodes
   - no competing chapter art
   - fewer decorations
   - more whitespace

Bunny English remains warmer and more teacher-led than the reference. Bunny is still the teacher, not a decorative reward mascot.
